<h2>
  🚀 Proyectos destacados
</h2>

### 🔧 MotorDesk

**ERP para talleres mecánicos y concesionarios**

Aplicación empresarial Full Stack diseñada para gestionar procesos reales de un taller y concesionario.

**Principales funcionalidades:**

- Gestión de clientes y vehículos.
- Órdenes de trabajo.
- Facturación y presupuestos.
- Gestión de stock y almacén.
- Pedidos a proveedores.
- Garantías.
- Agenda y citas.
- Gestión de usuarios, roles y permisos.
- Generación automática de PDF y códigos QR.
- Envío de documentación mediante WhatsApp y Email.
- Integración con sistemas de facturación y VERI*FACTU.

**Stack**

`Angular` · `TypeScript` · `Python` · `FastAPI` · `PostgreSQL` · `SQLAlchemy` · `Alembic` · `JWT` · `REST API`

---

### 📈 FC Market Intelligence

**Sistema de análisis de mercado y detección de oportunidades**

Proyecto desarrollado en Python para recopilar y analizar datos históricos de mercado, evaluar señales y detectar posibles oportunidades mediante métricas de rentabilidad.

**Características:**

- Históricos de precios.
- Catálogo automatizado de jugadores.
- Sistema de watchlist.
- Análisis de ROI.
- Seguimiento de señales.
- Evaluación automática de resultados.
- Persistencia mediante SQLite.
- Procesamiento asíncrono de datos.

**Stack**

`Python` · `SQLite` · `Data Analysis` · `AsyncIO` · `Algorithms`

---

### 🤖 Daiki AI

**Chatbot Full Stack basado en modelos de Inteligencia Artificial**

Aplicación conversacional desarrollada integrando modelos de lenguaje locales con una arquitectura frontend/backend.

**Características:**

- Integración con modelos LLM.
- Backend mediante API REST.
- Interfaz conversacional.
- Historial de conversaciones.
- Ejecución de modelos de IA en local.

**Stack**

`Python` · `FastAPI` · `Angular` · `Ollama` · `LLM`

🔗 [Ver proyecto](https://github.com/Marioph03/daiki-chatbot-inteligente)

---

### 🔐 LeakSentry

**Sistema de monitorización y detección de posibles filtraciones de información**

Plataforma orientada a ciberseguridad capaz de analizar fuentes, detectar coincidencias y evaluar riesgos automáticamente.

**Características:**

- Monitorización programada.
- Motor de evaluación de riesgo.
- Análisis automático de detecciones.
- Integración con diferentes fuentes y herramientas.
- Dashboard de resultados.

**Stack**

`Python` · `FastAPI` · `Angular` · `SQLAlchemy` · `APScheduler` · `Cybersecurity`
